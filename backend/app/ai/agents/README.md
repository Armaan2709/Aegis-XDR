# Specialized Autonomous AI Security Agents Directory

Hosts individual autonomous agent definitions.

## Planned Specialized Agents
1. **Threat Hunter Agent**: Proactively hunts for IOCs and behavioral anomalies.
2. **Malware Analyst Agent**: Performs static/dynamic analysis evaluation.
3. **DFIR Investigator Agent**: Analyzes forensic memory dumps, disk artifacts, and PCAPs.
4. **Threat Intelligence Agent**: Correlates IOCs with external threat feeds (VirusTotal, MISP, OTX).
5. **Detection Rule Generator Agent**: Synthesizes Sigma & YARA rules from investigation evidence.
6. **Incident Commander Agent**: Synthesizes agent consensus, determines severity, and proposes remediation actions.
