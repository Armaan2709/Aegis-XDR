# External Threat Intelligence & Security Integrations

Houses connectors for querying third-party threat feeds and telemetry backends.

## Future Connectors
- **VirusTotal**: File hash, URL, and IP reputation lookup.
- **AbuseIPDB**: IP address geolocation & malicious report scoring.
- **AlienVault OTX**: Open Threat Exchange pulse querying.
- **MISP**: Malware Information Sharing Platform threat feed sync.
- **Elasticsearch**: Log search & SIEM query interface.
- **Ollama**: Local LLM server connection.
