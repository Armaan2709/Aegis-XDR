# AegisAI XDR — System Documentation & Specifications

This directory contains architecture specifications, threat models, API references, and operations documentation.

## Directory Contents

- `architecture/`: System design diagrams, C4 models, and component flowcharts.
- `threat_model/`: STRIDE threat modeling analysis and enterprise security controls mapping.
- `api/`: OpenAPI exported specs and Postman collections.
- `runbooks/`: Operational runbooks for incident investigation, system recovery, and maintenance.
