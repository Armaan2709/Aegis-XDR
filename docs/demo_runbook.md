## 📋 Scenario Deep-Dive & Expected Agent Outputs

### Scenario 1: Credential Compromise (`credential_compromise`)
- **Purpose**: Demonstrates identity threat detection, LSASS memory access detection, and host containment.
- **How to Start**: Navigate to `/demo`, select `Credential Compromise & LSASS Dump`, click **RUN SYNTHETIC SCENARIO**.
- **Expected Alert**: Ingests 3 correlated alerts (`SYN-ALERT-101`, `102`, `103`).
- **Expected Correlation**: Correlates alerts into a single incident with Risk Score $\ge 85.0$.
- **Expected MITRE Mapping**: T1078 (Valid Accounts), T1003.001 (LSASS Memory), T1021.002 (WMI).
- **Expected Threat Hunter Output**: Formulates hypothesis for credential dumping and lateral movement.
- **Expected DFIR Output**: Reconstructs process tree: `powershell.exe -enc ...` → `rundll32.exe comsvcs.dll MiniDump`.
- **Expected Threat Intel Output**: Flags C2 IP `185.220.101.5` with reputation score `0.92`.
- **Expected Detection Output**: Synthesizes Sigma rule candidate for LSASS memory dump.
- **Expected Incident Commander Output**: Recommends host isolation and user account disablement.
- **Expected CaseApproval State**: Status = `PENDING` (pauses pipeline until analyst clicks **APPROVE**).
- **Expected SOAR State**: Executes `ISOLATE_HOST_MOCK` in `SAFE_MOCK_EXECUTION` mode upon approval.
- **Expected Final Result**: All 20 assertions pass; pipeline reaches `COMPLETED` status.

### Scenario 2: Ransomware Simulation (`ransomware_simulation`)
- **Purpose**: Demonstrates ransomware outbreak detection, VSS shadow copy protection, and rapid containment.
- **Expected Alert**: Ingests 3 alerts (`SYN-ALERT-201`, `202`, `203`).
- **Expected Correlation**: Incident created with Risk Score $\ge 90.0$ (`CRITICAL`).
- **Expected MITRE Mapping**: T1490 (Inhibit System Recovery), T1486 (Data Encrypted for Impact).
- **Expected Threat Hunter Output**: Flags rapid file modification and `vssadmin.exe` execution.
- **Expected DFIR Output**: Identifies parent-child spawn: `cmd.exe` → `vssadmin.exe delete shadows /all /quiet`.
- **Expected Threat Intel Output**: Tags ransomware strain signature hashes.
- **Expected Detection Output**: Synthesizes Suricata NIDS rule and Sigma shadow deletion rule.
- **Expected Incident Commander Output**: Recommends immediate network segment isolation.
- **Expected CaseApproval State**: Status = `PENDING` (Awaiting review).
- **Expected SOAR State**: Executes simulated network port block and process termination.
- **Expected Final Result**: 20/20 assertions pass.

### Scenario 3: Data Exfiltration (`data_exfiltration`)
- **Purpose**: Demonstrates sensitive data staging and covert DNS/HTTPS exfiltration detection.
- **Expected Alert**: Ingests 3 alerts (`SYN-ALERT-301`, `302`, `303`).
- **Expected Correlation**: Incident created with Risk Score $\ge 75.0$ (`HIGH`).
- **Expected MITRE Mapping**: T1560.001 (Archive via Utility), T1041 (Exfiltration Over C2 Channel).
- **Expected Threat Hunter Output**: Formulates exfiltration hypothesis based on byte count metrics.
- **Expected DFIR Output**: Pinpoints `7z.exe a -p secret.7z C:\Users\Public\*.docx`.
- **Expected Threat Intel Output**: Flags exfiltration domain `exfil-c2.darknet-node.xyz`.
- **Expected Detection Output**: Synthesizes YARA rule for encrypted archive pattern.
- **Expected Incident Commander Output**: Recommends blocking C2 domain and revoking user tokens.
- **Expected CaseApproval State**: Status = `PENDING`.
- **Expected SOAR State**: Executes mock firewall domain block.
- **Expected Final Result**: 20/20 assertions pass.


### 2. Run Scenario with Manual Approval Gate
```bash
curl -X POST "http://localhost:8000/api/v1/demo/run" \
  -H "Content-Type: application/json" \
  -d '{"scenario_id": "credential_compromise", "auto_approve": false}'
```
